Adding an Accident Report
=========================

To add an accident report, there are two options:

* Click the **+** button on the page displaying the list of accident reports.
* Click on **the police module** in the right menu, then select **add an accident**.

The image below illustrates these two possibilities.

.. image:: ../Images/img-police1&2/int_acc.jpg
    :name: Police/Gendarmerie Home
.. centered:: Police/Gendarmerie Home

After clicking on the add accident report icon, several steps will be presented 
to enter accident details. The information to be provided includes:

* :ref:`Inspector's information <refPoliceAgentConstatateur>`
* :ref:`Location details <refPoliceLocalisation>`
* :ref:`Accident information <refPoliceInfosAccident>`
* :ref:`Road information <refPoliceRoute>`
* :ref:`Involved vehicles <refPoliceVehiculesConsernes>`
* :ref:`Involved users <refPoliceUsagersConcernes>`
* :ref:`Sketch <refPoliceCroquis>`
* :ref:`A deposition <refPoliceDepositions>`

A detailed explanation of the accident report procedure follows:

.. _refPoliceAgentConstatateur:

Inspector
---------

This is the first section to fill out; it involves entering the 
identification details of the inspecting officer or officers if multiple agents 
are handling the report.

The interface for this step is shown below:

.. image:: ../Images/img-police1&2/PoliceAgentConstatateur.jpg
.. centered:: Inspector Information

As illustrated above, you can add multiple inspectors by clicking the **+ Agent** button.

.. image:: ../Images/img-police1&2/PoliceDeuxiemeAgentConstatateur.jpg
.. centered:: Second Inspector

Proceed to the next step by clicking the **Next** button.

.. _refPoliceLocalisation:

Location
--------

To enter the accident location, there are two methods:

**Method 1:** Enter location details manually

Manually input the following details:

* Region
* Department
* City
* Municipality
* Neighborhood
* Landmark
* Latitude
* Longitude

Then, click **Next** to complete this step and proceed.

**Method 2:** Select on the map

For those preferring to use the map, locate the accident zone, select the position, 
then click **Next** to proceed.

The image below illustrates both methods.

.. image:: ../Images/img-police1&2/PoliceLocalisation.jpg
.. centered:: Location Information

Proceed to the next step by clicking **Next**.

.. image:: ../Images/img-police1&2/PoliceLocalisationBoutonSuivant.jpg
.. centered:: Next button

Sketch
------

To insert the accident sketch, two options are available:

* Draw the sketch directly within the application.
* Upload an image of the sketch.

The image below illustrates both methods.

.. _refPoliceInsererCroquis:

.. image:: ../Images/img-police1&2/PoliceInsererCroquis.jpg
.. centered:: Insert a Sketch

**Method 1:** Draw within the application

To draw within the application, click the **Draw** button, as illustrated above.

.. image:: ../Images/img-police1&2/PoliceZoneDessin.jpg
.. centered:: Drawing Area

Proceed to the next step by clicking **Next**, as indicated in 
:ref:`the following image <refPoliceInsererCroquis>`.

**Method 2:** Upload an image

To upload a sketch image, click the upload button, as shown in 
:ref:`the following image <refPoliceInsererCroquis>`. A window will appear to 
search for and import the sketch image.

.. image:: ../Images/img-police1&2/PoliceImporterCroquis.jpg
.. centered:: Upload sketch image

Proceed to the next step by clicking **Next**, as indicated in 
:ref:`the following image <refPoliceInsererCroquis>`.

.. _refPoliceDepositions:

Depositions
-----------

Upon reaching the deposition creation section, the interface below appears.  
Here, you can create a new deposition by clicking the **+** button, as shown in 
the image below. Additionally, you can enter observations on the right and 
remarks on the left.

.. image:: ../Images/img-police1&2/PoliceCreerDeposition.jpg
.. centered:: Create a Deposition

Clicking the **+** button brings up a window where you must enter 
the deponent’s information, the deposition date, and the questions asked 
along with their responses.

.. image:: ../Images/img-police1&2/PoliceNewDeposition.jpg
.. centered:: Enter deposition details

To add interview questions and responses, click **+ Question**. A section 
for filling in the details appears as follows. After completing all information,  
click **Save** to finalize the deposition.

.. image:: ../Images/img-police1&2/PoliceNewDepositionQuestion.jpg
.. centered:: Add questions

Once a deposition is added, it appears as follows:

.. image:: ../Images/img-police1&2/PoliceListeDepositionsCrees.jpg
.. centered:: List of depositions

Clicking the witness's name in the deposition display allows you to view 
the entire interview.

Once all depositions have been entered, click **Finish** to save all depositions.

.. image:: ../Images/img-police1&2/PoliceVoirQuestionsRéponses.jpg
.. centered:: Witness interview
